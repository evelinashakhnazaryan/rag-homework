# Ноутбуки

- `00_validation.ipynb`: выполненные проверки загрузчика и русской токенизации.
- `01_colab.ipynb`: фактический прогон трёх моделей/режимов в Colab T4 25.09.2026 с сохранёнными выводами. Это журнал исходного запуска с загрузкой ZIP и исправлением совместимости зависимостей.
- `02_reproduce.ipynb`: чистый сценарий повторения из GitHub. Использует итоговые модули и закреплённые vLLM/Transformers; создаёт отдельный каталог результатов.

Для повторения откройте `02_reproduce.ipynb` в Colab, выберите GPU T4 и добавьте `GROQ_API_KEY` в Secrets.
