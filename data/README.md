# Исходные данные

В этой папке находятся articles.json, questions.json и ground_truth.json,
полученные пользователем от преподавателя 25 сентября 2026 года.
Проверено: 10 статей, 50 вопросов, 50 эталонов; ID вопросов и ответов совпадают.

Поддерживаются списки строк, списки объектов с id и словари id → текст.
Канонические поля: text (статьи), question (вопросы), answer (эталоны).
Для объектов используйте одинаковые ID вопросов и ответов. Для списков строк ID —
позиция, поэтому необходимо одинаковое исходное расположение вопросов и эталонов.
Загрузчик проверяет 10 статей, 50 вопросов, отсутствие дубликатов и совпадение ID.
Исходные файлы содержат списки объектов с явными ID и каноническими полями.
